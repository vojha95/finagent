## Changes from v1 (issues #131, #132)

- Data: the generator now tidies slot-filling artefacts (`tidy` in `finagent/planner/intent_data.py`):
  "Lowe's's" → "Lowe's", "in in" → "in", "base case case" → "base case". 53 of 3,026 questions
  changed. Goals, families, the split and the seed are unchanged.
- Compiler: a named scenario phrase now wins any overlap with an ambiguous one ("no stress case"
  is Base). This changes no training data.
- Validation, v1 → v2: clause accuracy 0.872 → 0.872, macro-F1 0.867 → 0.867, threshold 0.875 →
  0.875 (precision 0.985 both; coverage 0.651 → 0.655), fallback rate 0.349 → 0.345, C 0.125 →
  0.125, temperature 0.247 → 0.246. Compile accuracy (M1): 0.744 → 0.748 with the #131 fix alone
  (v1 model and data) → 0.752 with the v2 data and model. M0 0.273 → 0.273. Every M1 error is still
  a clarification (LOW_CONFIDENCE except one false ADVICE). No AMBIGUOUS_SCENARIO errors are left.
